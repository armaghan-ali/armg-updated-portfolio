## GitHub Pages
1. Create a GitHub account.
2. Create a repository named `YOURUSERNAME.github.io`.
3. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
4. GitHub → repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
5. Your public URL will be `https://YOURUSERNAME.github.io`.
