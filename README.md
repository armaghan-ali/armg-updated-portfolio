## GitHub Pages
1. Create a GitHub account.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. GitHub → repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Project website URL: `https://armaghan-ali.github.io/armg-updated-portfolio/`.
